# dsh-evolve-forge · 进化炉（插件）

把「自我学习／自我迭代／自我进化／issue log」四炉写成**常驻系统提示区块 + 台账工具**。

## 为什么不是简单包一层脚本

`四链错题官.py`、`错题官执行器.py`、`能力固化器.py`、`手感结晶器.py` 都把根目录写死在
`<workspace>`，而本机没有这个目录——它们跑起来要么报错，要么静默建成空账。
包一层＝把死件搬进提示。故本插件直接读写现有台账，只有动作拦截转调活件
`scripts/错题拦截器.py`（它按相对路径取件，没写死根）。

## 四炉

1. **错题炉**：同错二犯必立案；一案四链（根因→教训→复盘→顿悟＋泛化）；动手前拦截、交付前扫件；只增不删。
2. **固化炉**：能力＝名称＋可机械复现的验收命令＋状态；退步转回炉，修好再登记迭代。
3. **沉淀炉**：能脚本化的不留对话里；同类第二次必抽象；收尾三选一（落脚本／落条款／标一次性）。
4. **校准炉**：置信度事后核账；异常好结果同等归因；事故必产出一个机械检查项。

## 工具 `ql_evolve`

| action | 干什么 | 写盘 |
|---|---|---|
| `错题统计` | issue log条数、类型分布、四链缺口提示、末五条 | 无 |
| `错题查` | 关键词过滤issue log与四链账 | 无 |
| `错题立案` | 原子追加一行（时间／类型／源／错误／案由） | **写issue log** |
| `固化账` | 总数／稳固率／回炉中／累计退步／末三条 | 无 |
| `动作拦截` | `错题拦截器.py --拦 "拟做什么"`，命中即 BLOCK | 无 |
| `文件扫` | `错题拦截器.py --查 路径` | 无 |

## 配置

| 字段 | 默认 | 含义 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `order` | `90` | 区块排序（接在执行序之后） |
| `tool` | `true` | 是否挂工具 |
| `root` | 自动 | 工作区根 |

## 诚实边界

- **四链未自动补**：立案只写一行错题；根因／教训／复盘／顿悟仍要真人（Agent）想，脚本补不出思想。
- **`Smart Agent文明/` 树不在本机**：手感库、复盘台账、顿悟链台账、判断档案都在旧沙箱树里，本机缺；
  所以本插件只用本机在盘的台账（issue log／四链／固化账／名册／事件台账）。
- 动作拦截的规则集在 `错题拦截器.py` 里（约 20 组，注 L-XX 源号），命中与否以它的输出为准。
